## Part.0 前情提要

- 这篇题解与本题的其他题解有许多不同，其他题解无一例外全部是三叉线段树，而这篇题解，是适合初学线段树的同学学习的，基础二叉线段树题解。
- 只需了解线段树这种数据结构，或者能独立用线段树写出单点修改，查询区间加就能完全看懂这篇文章。

## Part.1 简要题意

给定一个长度为 $3^N$ 的只包含 A 和 B 的字符串。每次将相邻三个字符合并为一个字符，三个字符中出现次数较多的字符作为合并结果，重复 $N$ 次操作后得到只剩下一个字符。

接下来有 $Q$ 次操作，每次翻转指定位置的字符（A 变 B，B 变 A），要求输出每次操作后最终剩下的那个字符。

## Part.2 思路解析

### 2.1 思路简述

对于一个已经学习线段树很久的人来说，遇到此题，会直接写出三叉线段树来维护这个序列，这当然是代码长度与时间复杂度都最优的选择，但是本人比较菜，只会普通的二叉线段树，所以考虑用二叉线段树维护这个东西。

我们注意到每次操作初始长度为 $3^N$ 的字符串，只需要经过 $N$ 此次操作就可以得到最后剩余的字符串，所以考虑用 $N$ 棵线段树维护每次操作前的字符串，编号从 $1$ 到 $n$，第 $i$ 个字符串的大小为 $3^i$，每个线段树维护对应字符串的 A 的数量， 最后查询第一个字符串中的 A 字符数量是否大于 $2$，如果大于就是输出 A，否则输出 B。

我们根据思路开始实现代码。

### 2.2 建树

建树部分的难点，主要在于编号为 $i$ 的字符串，怎样从编号为 $i+1$ 的字符串转移而来，其实非常简单，对于编号为 $N$ 的字符串，直接统计就可，否则，对于第 $i$ 个字符串的第 $x$ 个节点，可以从第 $i+1$ 个字符串的第 $x\times 3-2$ 到第 $x\times 3$ 个节点的 A 的数量决定，只要在这个区间内，A 的数量大于等于 $2$，这个节点的状态就为 $1$，否则为 $2$，然后进行最基础的区间合并。

建树及区间合并的代码如下：

```cpp
//u0 表示这个区间里 A 字符的数量。
//p 表示这个线段树所维护的字符串的编号。
//为了方便，我们将字符串的 A 字符处理成了 数字 0，将 B 字符处理成了 1。
void pushup(int p,int x) {
    tree[p][x].u0=tree[p][lc(x)].u0+tree[p][rc(x)].u0;
    //将这个区间的左儿子和右儿子的 A 字符的数量相加。
}
void build(int p,int x,int l,int r) {
    tree[p][x].l=l;
    tree[p][x].r=r;
    if(l==r) {
        if(p==n) {
            if(a[l]==0) {
                tree[p][x].u0=1;
            }
            else {
                tree[p][x].u0=0;
            }
        }
        else {
            //query(p,x,l,r) 函数查询的是：编号为 p 的字符串中区间 [l,r] 中的 A 字符数量。
            //后面会提到这个函数。
            if(query(p+1,1,l*3-2,l*3)>=2) {
                tree[p][x].u0=1;
            }
            else {
                tree[p][x].u0=0;
            }
        }
        return;
    }
    int mid=(l+r)>>1;
    build(p,lc(x),l,mid);
    build(p,rc(x),mid+1,r);
    pushup(p,x);
}
```

### 2.3 单点修改

单点修改操作与建树相同，编号为 $N$ 的字符串直接修改，编号为 $i$ 的字符串的第 $x$ 个字符，也是第 $i+1$ 个字符串的第 $x\times 3-2$ 到第 $x\times 3$ 个节点的 A 的数量决定，由于与建树的过程基本一致，这里不再赘述。

单点修改的代码：
```cpp
void change(int p,int x,int id) {
    if(tree[p][x].l==tree[p][x].r) {
        if(p==n) {
            tree[p][x].u0^=1;
        }
        else {
            if(query(p+1,1,tree[p][x].l*3-2,tree[p][x].l*3)>=2) {
                tree[p][x].u0=1;
            }
            else {
                tree[p][x].u0=0;
            }
        }
        return;
    }
    int mid=(tree[p][x].l+tree[p][x].r)>>1;
    if(id<=mid) {
        change(p,lc(x),id);
    }
    else {
        change(p,rc(x),id);
    }
    pushup(p,x);
}
```

### 2.4 查询

与普通的线段树查询一致，唯一的区别就是增加了编号，代码如下：
```cpp
int query(int p,int x,int l,int r) {
    if(l<=tree[p][x].l&&tree[p][x].r<=r) {
        return tree[p][x].u0;
    }
    int mid=(tree[p][x].l+tree[p][x].r)>>1,da=0;
    if(l<=mid) {
        da+=query(p,lc(x),l,r);
    }
    if(mid<r) {
        da+=query(p,rc(x),l,r);
    }
    return da;
}
```

### 2.5 主函数

由于我们的建树与单点修改中已经可以通过输入编号自动处理了，所以直接用 ```for``` 循环，从后往前处理每一个字符串即可。

主函数代码：
```cpp
//FOR(a,b,c) for(int a=(b),a##end=(c);a<=a##end;a++)
//ROF(a,b,c) for(int a=(b),a##end=(c);a>=a##end;a--)
cin>>n>>q;
FOR(i,1,qpow(3,n)) {
    char c;
    cin>>c;
    if(c=='A') {
        a[i]=0;
    }
    else {
        a[i]=1;
    }
}
ROF(i,n,1) {
    //从后往前处理每一个编号的字符串，编号每减 1，总长度就除以 3。
    seg.build(i,1,1,qpow(3,i));
}
while(q--) {
    int id;
    cin>>id;
    ROF(i,n,1) {
        //从后往前进行单点修改，注意每次修改的 id 都要进行变动，具体为 id=(id+2)/3。
        seg.change(i,1,id);
        id=(id+2)/3;
    }
    if(seg.query(1,1,1,3)>=2) {
        cout<<"A\n";
    }
    else {
        cout<<"B\n";
    }
}
```

## 时间复杂度

单次建树：$O(3^N)$。\
单词修改：$O(N)$。\
建树：$O(N3^N)$。\
查询：$O(QN^2)$。\
时间复杂度：$O(N3^N+QN^2)$。
