Part.1 美化前的准备

一提到网页的美化与修改，都绕不过两个著名的插件：Stylus 和 Tampermonkey（以下简称篡改猴），其中 Stylus 主要负责网页的 css，而篡改猴不仅可以修改 css，还可以对 js 进行修改，所以经常对美化网页起到美化与维护的作用（当然也有很多非常好用的插件，下文会提到）。

1.1 Stylus 的下载

如果你用的是 Google 浏览器，并且可以找到 Stylus 的商店，可以链接直达，如果不可以，或者使用其他浏览器，我会给出一个通用的方案。

首先点击这个链接，去到 Stylus 的 github 发布页，点击对应的浏览器下载（不是 chrome 或者 furefox 可以点第三个，如果不行可以上网查一查教程）。

随后，将下载好的压缩包拖进我的扩展，等他下载好就可以看到了。

1.2 篡改猴的下载

篡改猴相比 Stylus 更加简单，在扩展商店里找到篡改猴，直接获取就可以了。

搞好准备工作就可以正式开始美化了。

Part.2 洛谷

众所周知，在 $2026$ 之间，洛谷的美化社区非常丰富，有氩洛谷，Smart-luogu 等高质量美化样式。但是，洛谷在 $2026$ 年进行了多次重大更新，包括多次主题商店的变化及 css 模板的变更，这使得这些插件的功能都收到了影响。

不过，好在现在新生代洛谷美化插件已经在逐渐冒头，如可高度自定义的氧洛谷 $2026$，氩洛谷 $2.0$，等等，大家可以去 Stylus 的洛谷插件社区查看，不过今天，我要重点介绍的是洛谷新生代的优化主题，由 Stars-Twinkle 编写的：BigBallOfMud Luogu。

Part.0 前情提要 这篇题解与本题的其他题解有许多不同，其他题解无一例外全部是三叉线段树，而这篇题解，是适合初学线段树的同学学习的，基础二叉线段树题解。 只需了解线段树这种数据结构，或者能独立用线段树写出单点修改，查询区间加就能完全看懂这篇文章。 Part.1 简要题意给定一个长度为 $3^N$ 的只包含 A 和 B 的字符串。每次将相邻三个字符合并为一个字符，三个字符中出现次数较多的字符作为合并结果，重复 $N$ 次操作后得到只剩下一个字符。 接下来有 $Q$ 次操作，每次翻转指定位置的字符（A 变 B，B 变 A），要求输出每次操作后最终剩下的那个字符。 Part.2 思路解析2.1 思路简述对于一个已经学习线段树很久的人来说，遇到此题，会直接写出三叉线段树来维护这个序列，这当然是代码长度与时间复杂度都最优的选择，但是本人比较菜，只会普通的二叉线段树，所以考虑用二叉线段树维护这个东西。 我们注意到每次操作初始长度为 $3^N$ 的字符串，只需要经过 $N$ 此次操作就可以得到最后剩余的字符串，所以考虑用 $N$ 棵线段树维护每次操作前的字符串，编号从 $1$ 到 $n$...
